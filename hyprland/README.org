#+TITLE:        Hyprland config
#+AUTHOR:       Thomas L.

Ma config Hyprland complète (base [[https://github.com/JaKooLit/Hyprland-Dots][JaKooLit Hyprland-Dots]] v2.3.20, portée en Lua pour Hyprland 0.57),
avec waybar, kitty, rofi, swaync, wlogout, wallust et quickshell.
Testée sur Ubuntu 24.04 (noble).

* Switch rapide (nouvelle machine)

#+begin_src sh
git clone <ce repo> ~/repo/dot-stuff
cd ~/repo/dot-stuff/hyprland
./install.sh              # paquets + polices + Waterfox + configs
# ou : ./install.sh --configs   (copie juste les configs)
#+end_src

Puis :
1. Installer à la main ce que le script signale comme =MANQUANT= (voir [[*À installer à la main][À installer à la main]]).
2. Copier les fonds d'écran (1,1 Go, pas dans git) : =~/Pictures/wallpapers/=
   #+begin_src sh
   rsync -a portable:~/Pictures/wallpapers/ ~/Pictures/wallpapers/
   #+end_src
3. Se déconnecter et choisir la session *Hyprland* dans le gestionnaire de connexion.
4. Adapter les écrans si besoin (voir [[*Spécifique à la machine][Spécifique à la machine]]).

Les configs déjà présentes dans =~/.config= sont renommées en =<dossier>.bak-<date>= avant la copie.

* Organisation de la config

| Fichier                          | Contenu                                                                 |
|----------------------------------+-------------------------------------------------------------------------|
| =hypr/hyprland.lua=              | config principale : écrans, clavier, marges, bordures, règles, bureaux 1-6 persistants |
| =hypr/lua/keybinds.lua=          | tous les raccourcis (port des raccourcis JaKooLit)                      |
| =hypr/lua/startup.lua=           | programmes lancés au démarrage (waybar, swaync, swww, nm-applet...)     |
| =hypr/themes/catppuccin-mocha.lua= | couleurs Catppuccin Mocha                                             |
| =hypr/scripts/=, =hypr/UserScripts/= | scripts JaKooLit (certains corrigés pour 0.57) + scripts perso     |
| =waybar/configs/[TOP] Default Laptop= | modules de la barre (lien =waybar/config=)                         |
| =waybar/ModulesWorkspaces=, =ModulesCustom=, =Modules=, =style.css= | définition et style des modules     |

Attention : depuis Hyprland 0.57, seuls les fichiers =.lua= sont lus. Les =*.conf= de JaKooLit
(=hypr/configs/=, =hypr/UserConfigs/=) sont gardés pour référence mais *ignorés*.

* Réglages perso
- Clavier : =us= variante =intl= (touches mortes), Caps Lock = Ctrl (=ctrl:nocaps=).
- Écran : échelle 1.2, aucune marge (=gaps_in= / =gaps_out= = 0).
- Pas de bordure quand une seule fenêtre est visible ; bordure lavande dès 2 fenêtres.
- Barre : bureaux 1 à 6 toujours affichés, avec un point (•) quand le bureau contient des fenêtres
  (script =hypr/UserScripts/WorkspaceState.py=, lancé au démarrage) ; horloge 24h + date JJ/MM/AAAA ;
  bouton casque = choix sortie son (clic gauche) / entrée son (clic droit) via =UserScripts/AudioSwitch.sh=.
- Kitty : police taille 11.
- Navigateur : Waterfox pour Win+B et la barre ; navigateur par défaut du système laissé à Edge
  (à régler avec =xdg-settings set default-web-browser ...= sur la nouvelle machine).

Liste complète : =hypr/lua/keybinds.lua=.

* Spécifique à la machine
- *Écrans* : =hypr/hyprland.lua=, bloc =hl.monitor= (règle générique : résolution native, position auto,
  échelle 1.2). Sur un PC fixe avec un grand écran, essayer =scale = 1= ; ajouter un bloc =hl.monitor({ output = "DP-1", ... })=
  par écran pour fixer positions/résolutions (=hyprctl monitors= pour les noms).
- *Barre* : la config waybar s'appelle « Laptop » (batterie, luminosité) ; sur un fixe ces modules
  restent simplement vides. Win+Alt+B permet de choisir une autre disposition.
- *Pavé tactile* : =hypr/UserConfigs/Laptops.conf= / =TouchPad.sh=, inutile sur un fixe.

* Mettre à jour cette sauvegarde (depuis la machine de référence)
#+begin_src sh
D=~/repo/dot-stuff/hyprland
rsync -a --delete --exclude 'wallpaper_effects/' ~/.config/hypr/ $D/hypr/
for d in waybar kitty rofi swaync wlogout wallust quickshell; do rsync -a --delete ~/.config/$d/ $D/$d/; done
#+end_src
